# The World in One Day, Sunday 22 November 2026

A one-page newspaper front page summing up the world news of
Sunday 22 November 2026, drawn entirely in code.

## Run

```
python3 main.py
```

Writes the poster to `/output/entry.png` (1024x1024 PNG).
Pure Python standard library: no network, no clock, no randomness,
so two runs produce byte-identical output.
